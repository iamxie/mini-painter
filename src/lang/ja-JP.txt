# mpainter 言語ファイル：日本語
# このファイルは他の言語を追加するときのテンプレートにもなります。
# This file also serves as the template for adding another language.
#
# 使い方 / How to add a language:
#   1. このファイルを lang\<言語コード>.txt にコピーする（mpainter.exe と同じ場所の lang フォルダー）。
#      Copy this file to lang\<code>.txt in a "lang" folder next to mpainter.exe.
#   2. 下の _code と _name を書き換える。_code は言語コード（ファイル名と同じにするとよい）、
#      _name は「言語 / Language」メニューに表示される名前。
#      Change _code (language code, ideally the same as the file name) and _name (shown in the Language menu).
#   3. 各行の = の右側を翻訳する。訳していない行は英語のまま表示される。
#      Translate the right-hand side of each line. Untranslated lines fall back to English.
#   4. UTF-8 で保存する（BOM あり・なしどちらでも可）。
#      Save as UTF-8 (with or without BOM).
#
# 書式 / Format:
#   一行一項目。「英語原文=翻訳」。# か ; で始まる行はコメント。
#   One entry per line: English=Translation. Lines starting with # or ; are comments.
#   エスケープ / Escapes: \n 改行 newline, \t タブ tab, \\ バックスラッシュ backslash, \= 等号 equals sign.
#   原文に = が含まれる場合は \= と書く。 Write \= for an equals sign inside the English text.
#   %d %s %u %lu %llu %.0f %08X はプログラムが値を埋める場所。順番どおりに残す。
#   %d %s %u %lu %llu %.0f %08X are filled in by the program; keep them in the same order.
#   &File のような & は、その次の文字をメニューのアクセスキーにする。
#   & in "&File" marks the next letter as the menu access key.
_code=ja-JP
_name=日本語
