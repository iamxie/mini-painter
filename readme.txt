mpainter — 輕量圖片檢視與標註工具
=====================================

免安裝（portable）。主程式是 mpainter.exe 一個檔案，放哪裡都能跑，
不需要 Visual C++ 可轉散發套件。旁邊的 7z.dll 只給「看壓縮檔」用，
不需要這功能可以刪掉。

使用方式
--------
- 把圖片拖到視窗上、「檔案 > 開啟」，或在命令列給路徑：mpainter.exe 圖片或資料夾
- 支援 BMP、TIFF、JPEG、PNG、WebP。
- 也能直接開 zip / 7z / rar（含 .cbz / .cb7 / .cbr）壓縮檔，把裡面的圖片當一個資料夾翻頁，見下方「壓縮檔」。
- ← → 翻同資料夾的上一張 / 下一張。開資料夾時從第一張開始。翻到底會提示「已經是最後一張了」。
- 看漫畫時把「顯示 > 翻到底時接著看下一個資料夾或壓縮檔」打開（預設關；內建的「漫畫模式」是開的）：
  翻到底先提示要去哪一本，3 秒內再按一次就跳到同一層的下一個資料夾或壓縮檔的第一頁；往前翻對稱。
  只找同一層：這個資料夾的子資料夾、裡面的壓縮檔都不算它的一部分，也不會往上一層找。
  開一個只有壓縮檔或子資料夾的資料夾，會直接開裡面第一本。
- 標示工具列（工具列右邊的筆按鈕）有塗鴉、直線 / 箭頭、形狀、文字、調整顏色、調整尺寸。
- Ctrl+S 存檔會把標註壓平到圖片裡並覆寫原檔。
  「檔案 > 輸出成」（Ctrl+Shift+S）把目前的畫面（含標註）寫成另一個檔，可以換格式；
  輸出後編輯中的還是原檔，不會切到新檔。沒有「另存新檔」。
  存檔會保留原檔的 EXIF、XMP、ICC（Orientation 會改成 1，因為圖已轉正）。
  輸出成裝不下這些資料的格式（例如 PNG、BMP）時會先提醒。
- ↑ ↓ 捲動。「顯示」選單可以選檢視模式：符合視窗、符合寬度（看 webtoon）、
  符合高度、實際大小、兩頁並排（看漫畫；寬圖自動單獨一屏，可切由右到左、
  第一張單獨、錯開一頁）。模式會記住，翻頁不變。
- 縮放品質（快速 / 高品質 Lanczos3）、捲到底再按 ↓ 翻頁、兩頁並排的選項，都是「模式」的一部分，見下一節。

模式（設定集）
--------------
- 「顯示 > 模式」列出你建立的模式，點一個就把整組檢視設定套上：開圖時的檢視模式、小圖放大、
  縮放品質、捲到底翻頁、翻到底接下一本、兩頁並排由右到左、第一張單獨、存檔的 metadata 警告。
  內建兩個：「一般模式」（實際大小、不接下一本、不並排、要警告）、「漫畫模式」（兩頁並排、
  接下一本、高品質縮放、不警告）。名字和內容都可以改，數量不限。
- 選了模式之後在「顯示」選單改的任何一項都算臨時調整：只影響這次，模式本體不動。標題列會在模式名
  後面加 *，選單上顯示「（已調整）」。想把調整變成新的基準，按「顯示 > 模式 > 儲存目前設定到「…」」。
  重開程式沿用關閉時的狀態，包括臨時調整。
- 切換模式只有兩個入口：「顯示 > 模式」選單、設定面板的「模式」tab。不會因為開了什麼檔自動切換。
  標題列尾端永遠顯示目前在哪個模式。
- 「編輯 > 設定」分四個 tab：一般（語言、教學提示、設定檔位置）、模式（新增 / 複製 / 重新命名 /
  刪除 / 使用此模式，右側是該模式的內容）、壓縮檔（解壓位置與目前用量、置頂檔名、密碼列表）、
  Windows 整合（右鍵選單、預設程式）。底部是 取消 / 確定 / 套用；「套用」立刻生效、面板不關。

壓縮檔（zip / 7z / rar）
-----------------------
- 開壓縮檔的方式和開圖片一樣：拖進視窗、「檔案 > 開啟」、命令列、檔案總管右鍵「用 mpainter 開啟」。
  .cbz / .cb7 / .cbr 也可以設成預設用 mpainter 開；.zip / .7z / .rar 只加右鍵選單，不搶壓縮軟體的關聯。
- 開啟時整個壓縮檔會先解到暫存資料夾，再把裡面所有支援格式的圖片攤平成一份清單，
  依路徑的自然排序翻頁（子資料夾的章節會接在一起）。跳過 __MACOSX、Thumbs.db 和點開頭的檔案。
  「編輯 > 設定」的「置頂檔名」清單（預設 cover.jpg / cover.png / cover.webp）會排到最前面，
  開一般資料夾時也一樣。
- 解出來的檔案在暫存資料夾裡用序號命名（00001.png…），畫面上顯示的是壓縮檔內的名字。所以名字裡有
  Windows 不允許的字元、或兩個檔案用錯的字碼頁解出同一個名字，都不會解失敗、不會少頁。舊 zip 沒標
  UTF-8 的檔名在不同語系的系統上會是亂碼，但每一張都看得到。某一頁損毀（CRC 錯）時那一頁略過，
  其他頁照開，開之前會提示少了幾張。
- 有密碼的壓縮檔：先把「編輯 > 設定」的「密碼列表」逐一試過（畫面會顯示正在嘗試），
  都不對才問。問到對的密碼會自動加進密碼列表。注意：密碼列表以明文存在 mpainter.ini。
- 壓縮檔裡的圖片是唯讀的：不能標註、調色、調整尺寸、儲存。要編輯請先用解壓縮軟體解開，
  再開解出來的檔案。旋轉（Ctrl+R）可以用，只是看的方便，翻頁就回復。
  「輸出成」可以用：把這一張（含旋轉）寫到壓縮檔旁邊的新檔，metadata 照抄。
- 暫存位置預設是 mpainter.exe 旁邊的 temp 資料夾（exe 放在寫不進去的地方時改用 %TEMP%\mpainter\unzip），
  可以在「編輯 > 設定 > 壓縮檔」改，那裡也會顯示實際使用中的位置和目前用量。注意：加密壓縮檔解出來的
  檔案在暫存資料夾裡是未加密的明文；關閉程式會刪掉，程式當掉的話下次任何一個 mpainter 啟動時會清掉。
  如果 mpainter.exe 放在 OneDrive / Dropbox 這類同步資料夾裡，解出來的圖也會被同步上去，建議把暫存位置改到別處。
- 這個功能靠 mpainter.exe 旁邊的 7z.dll（7-Zip 的元件）。沒有它就不能開壓縮檔，其他功能不受影響。
  可以自己換成同介面的其他版本 7z.dll（例如新版 7-Zip 的）。

語言
----
「語言 / Language」選單可以切換，內建繁體中文與英文，預設跟隨系統。
隨附的 lang\ja-JP.txt 是日文，檔頭有中日英對照的格式說明，也是新語系的範本。
想加別的語言：把 lang\ja-JP.txt 複製成 lang\<語系代碼>.txt（放在 mpainter.exe 旁的 lang 資料夾），
改檔頭的 _code 與 _name，逐行翻譯等號右邊即可。缺的句子會顯示英文。

設定檔 mpainter.ini
-------------------
設定存在 mpainter.exe 旁邊的 mpainter.ini，第一次執行時自動建立。
把 exe 和 ini 一起搬走，設定就跟著走。
視窗的位置、大小、是否最大化也記在裡面（window=），下次啟動照舊；每個模式一段 [profile]。
密碼（password=）前後的空白算密碼的一部分，用記事本編輯時請留意。
如果 exe 放在無法寫入的位置（光碟、沒有寫入權限的資料夾），設定會存不起來，
每次啟動都會回到預設值。「編輯 > 設定」會提示這件事。

右鍵選單「用 mpainter 開啟」
----------------------------
第一次執行時會自動在檔案總管的右鍵選單加入「用 mpainter 開啟」，
圖片檔和資料夾上都有。這只寫入目前使用者的登錄（HKEY_CURRENT_USER），
不需要系統管理員權限，也不影響其他程式。
可以在「編輯 > 設定」關掉，關掉就會移除。
把 mpainter.exe 搬到別的資料夾後，下次執行會自動更新路徑。
用新版 exe 覆蓋舊版後，右鍵選單的圖示可能還是舊的；這是檔案總管的圖示快取，
登出再登入（或重新啟動檔案總管）就會更新。

  Windows 11 的限制：Windows 11 的右鍵選單分兩層，這個項目在第二層，
  要按「顯示其他選項」（或選取檔案後按 Shift+F10）才看得到。
  要出現在第一層必須用 MSIX 打包安裝，和免安裝的設計衝突，所以沒有做。
  Windows 10 沒有這個問題。

設為預設的圖片程式
------------------
第一次開圖時會問要不要把 mpainter 設為預設程式。
Windows 8 以後不允許程式自己把自己設成預設值，只能由你在系統設定裡選：
- Windows 10：設定 > 應用程式 > 預設應用程式 > 依應用程式設定預設值 > mpainter > 管理。
- Windows 11：設定 > 應用程式 > 預設應用程式 > 搜尋 mpainter，逐一點每個副檔名改成 mpainter。
mpainter 會先把自己登錄到清單裡，並開啟上面的設定頁。
之後想改，到「編輯 > 設定 > 設為預設圖片程式…」。

移除
----
1. 「編輯 > 設定」取消勾選右鍵選單。
2. 刪掉 mpainter.exe 和 mpainter.ini。
3. 如果設過預設程式，Windows 會自動回到別的程式。登錄裡剩下的
   HKEY_CURRENT_USER\Software\mpainter 和 HKEY_CURRENT_USER\Software\Classes\mpainter.Image
   可以手動刪除，留著也無害。
